# Перезалив своих Shorts — Telegram-бот с мини-апкой

Бот берёт **самые просматриваемые** шортсы с твоих каналов, слегка их уникализирует
и публикует на другом твоём канале **по расписанию**: по одному, в случайное время
с 12:00 до 19:00 по Молдове (время и количество настраиваются).

Всё управление — в мини-апке внутри Telegram:

- **Проекты**: несколько твоих каналов-источников (**YouTube или TikTok**) → 1 канал для перезалива.
  Проектов сколько угодно, у каждого пользователя бота — свои.
- **Выбор видео** (из ещё не перезалитых, каналы-источники по очереди или общий топ):
  - **🔥 В тренде** (по умолчанию) — сначала ролики, которые набирают просмотры **прямо сейчас**
    (прирост за последние сутки: бот замеряет просмотры каждые 2 часа), а когда они закончатся —
    остальные по общему числу просмотров;
  - «Всего просмотров» — по просмотрам за всё время;
  - «В среднем/день» — просмотры ÷ дни с выхода;
  - фильтр «не старше N дней»;
  - фильтр по длине ролика «от … до … секунд» (например, только 15–60 с).
- **Подгонка длины при заливке** (проект → «Подгонять длину»): как есть / своя длина /
  «как на канале» (медиана лучших 30% роликов твоего канала, пока на нём мало роликов — источников).
  **Диапазон** — «плавающая» длина, например `1:35-2:35` (или `1.35-2.35`): ролик длиннее верхней
  границы укорачивается так, чтобы попасть в диапазон; ролики в диапазоне и короче не трогаются.
  Режет **бережно**: хук, поворот, шутка/пик эмоции и развязка не вырезаются, больше 60% ролика
  не вырезается никогда; если без потери смысла не уложиться — ролик остаётся чуть длиннее
  (в отчёте: «оставил 2:48 вместо 2:35, чтобы не потерять смысл»).
  Длинные ролики укорачиваются «умной обрезкой» перед уникализацией; если обрезать не вышло —
  ролик заливается целиком, а в уведомлении будет пометка.
- **⚡ Залить сейчас — бот выберет сам** (проект → «План»): сразу берёт лучший подходящий ролик
  по правилам проекта, не дожидаясь расписания.
- **Топ видео в панели**: у каждого ролика дата и время выхода, сколько дней назад, длительность,
  просмотры всего и в день; сортировка «Просмотры / В день / Новые».
- **Расписание**: «Авто» — N роликов в день в случайное время внутри окна, с промежутком
  между роликами (по умолчанию 2 в день, 12:00–19:00, 15–120 мин); «Своё время» — фиксированные часы.
- **Вручную**: любое видео можно залить сейчас, поставить в ближайший слот или на конкретные дату и время.
- **Публикация**: «Запланировать» — бот заранее загружает ролики как отложенные публикации,
  YouTube сам выкладывает их в назначенное время (после загрузки компьютер можно выключать;
  с 20:00 бот сразу готовит ролики на завтра). Или «Сразу» / по ссылке / приватное.
- **Куда отправлять**: на YouTube, **мне в Telegram** (готовое обработанное видео + название,
  описание и теги для копирования — выкладываешь сам, привязка канала не нужна) или оба.
- **Уникализация**: увеличение 5%, поворот −0.5°, тени светлее на 10%, размытие полос сверху и снизу
  (всё меняется в панели). Название и описание — как в оригинале, плюс `#shorts`.
- **Сообщения в Telegram**: ✅ каждая заливка со ссылкой, ❌ ошибки. Когда новые видео кончатся —
  бот предложит перезалить один из популярных роликов, сменить каналы или подождать новых.

## Установка на Windows (один раз)

### 1. Python и проект
1. Установи **Python 3.11+** с [python.org](https://www.python.org/downloads/) —
   при установке поставь галочку **Add python.exe to PATH**.
2. Скачай этот проект (Code → Download ZIP) и распакуй, например в `C:\ShortsBot`.

### 2. Бот в Telegram
1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя → получишь **токен**.
2. Запусти **`install.bat`**. Он поставит всё нужное и откроет файл `.env` — впиши туда
   `BOT_TOKEN=токен_от_BotFather` и сохрани.

### 3. Доступ к YouTube (Google Cloud)
1. Открой [console.cloud.google.com](https://console.cloud.google.com/) → создай проект.
2. **APIs & Services → Library** → найди **YouTube Data API v3** → **Enable**.
3. **OAuth consent screen** → тип **External** → заполни название и почту →
   в **Test users** добавь свой Gmail (тот, где каналы).
4. **Credentials → Create credentials → OAuth client ID** → тип **Desktop app** →
   **Download JSON** → переименуй файл в `client_secret.json` и положи в папку с ботом.

### 4. Запуск
1. Запусти **`start.bat`** — откроется окно бота (его не закрывать).
2. В Telegram напиши своему боту **`/start`** — ты станешь его владельцем, другим он отвечать не будет.
3. Нажми **«Панель»** (кнопка слева от поля ввода) → создай проект → добавь ссылки на свои каналы.
4. **«Привязать канал»** — делай это **в Telegram Desktop на этом же компьютере**: откроется
   браузер, войди в Google и **выбери канал, куда перезаливать**.
5. Готово — в разделе «План» появится время публикаций на сегодня.

Чтобы бот стартовал вместе с Windows — запусти **`autostart_on.bat`** (выключить — `autostart_off.bat`).

## Обновление через git (рекомендуется)

Один раз:
1. Установи [Git для Windows](https://git-scm.com/download/win) (все настройки по умолчанию).
2. Открой папку, где хочешь держать бота, в адресной строке Проводника напиши `cmd` и нажми Enter, затем:
   ```
   git clone -b claude/fervent-darwin-w73xbr https://github.com/nnenq/channel1.git ShortsBot
   ```
   Если репозиторий приватный — откроется окно входа в GitHub, войди.
3. Скопируй из старой папки бота в новую `ShortsBot`: файлы `.env`, `client_secret.json`
   и папки `data` (проекты, история, привязанные каналы) и `bin`.
4. В `ShortsBot` запусти `install.bat`, потом `start.bat`.

Дальше для обновления — **`update.bat`** (или `git pull` в папке бота), затем перезапуск `start.bat`.
Твои `.env`, `client_secret.json` и `data` git не трогает.

## Важно знать

- **Компьютер должен быть включён** в часы публикаций (по умолчанию 12:00–19:00). Пока бот запущен,
  он не даёт Windows уснуть. Если бот был выключен, пропущенная публикация переносится,
  а если опоздание больше 1,5 часа — пропускается (бот напишет об этом).
- **Адрес панели** (бесплатный туннель Cloudflare) теперь переживает перезапуск бота и меняется только
  после перезагрузки компьютера. Тогда бот сам пришлёт «🔄 Адрес панели обновился» со свежей кнопкой;
  в любой момент рабочую кнопку даёт команда **`/panel`**. Если кнопка «Панель» слева от поля ввода
  всё равно открывает старый адрес — закрой и снова открой чат с ботом (Telegram Desktop её кэширует).
  **Постоянный адрес навсегда** (необязательно, бесплатно): поставь [Tailscale](https://tailscale.com/download),
  войди, выполни в командной строке `tailscale funnel --bg 8080` и впиши выданный адрес
  `https://<имя-пк>.<...>.ts.net` в `.env` как `PUBLIC_URL=...` — тогда Cloudflare не нужен.
- **Приватные видео у новых Google-проектов.** YouTube может делать все видео, загруженные через
  API непроверенного проекта, **приватными**. Чтобы публиковать публично, пройди бесплатную проверку:
  [YouTube API Audit form](https://support.google.com/youtube/contact/yt_api_form).
  Пока проверки нет — проверь на первом ролике, какой статус он получил.
- **7 дней**: пока приложение Google в режиме «Testing», вход живёт ~7 дней — потом бот напишет
  «❌ … привяжи канал заново». Чтобы не повторять, на экране OAuth consent нажми **Publish app**.
- **Лимит YouTube API**: ~6 заливок в сутки на один Google Cloud проект. 2 ролика в день × 3 канала — ок.
  Для большего — ещё один Google Cloud проект (свой `client_secret.json`, отдельная папка с ботом)
  или запрос на увеличение квоты.
- Инструмент для **твоего собственного контента**. Одинаковые видео на разных каналах YouTube может
  счесть «повторно используемым контентом» (влияет на монетизацию), даже с уникализацией.

## Доступ к боту и пользователи

Ботом пользуешься ты (владелец: `OWNER_ID` в `.env` или первый, кто написал `/start`)
и только те, кому **ты сам** дал доступ:

- **Запрос:** человек пишет боту `/start` → тебе приходит «👤 … просит доступ»
  с кнопками **✅ Дать доступ / ❌ Отклонить** (отклонённым бот больше не отвечает).
- **Приглашение:** панель → «Доступ к боту» → **🔗 Создать ссылку-приглашение** → отправь человеку.
  Ссылка одноразовая и действует 24 часа.

**У каждого пользователя всё своё:** проекты, каналы, расписание, история и уведомления.
Чужие проекты не видны никому, включая владельца. Раздел «Доступ к боту» (видишь только ты) —
список людей; если забрать доступ, проекты человека встают на паузу.

Чтобы друзья могли привязать **свои** YouTube-каналы, включи вход по коду (ниже) и добавь их
Gmail в **Test users** на экране OAuth consent в Google Cloud (или опубликуй приложение).
Лимит YouTube API (~6 заливок в сутки на Google Cloud проект) общий на всех пользователей бота.

Защита: панель открывается только по адресу с секретным ключом и с подписью Telegram-аккаунта
с доступом; вход в Google через браузер принимается только на компьютере, где запущен бот; из групп
бот сам выходит (можно ещё в @BotFather: Bot Settings → Allow Groups → Turn off).

### Привязка канала по коду (с любого устройства)

1. Google Cloud → **Credentials → Create credentials → OAuth client ID** →
   тип **TVs and Limited Input devices** → **Create** → **Download JSON**.
2. Переименуй файл в `client_secret_tv.json` и положи рядом с `client_secret.json`, перезапусти бота.
3. В панели «Привязать канал» покажет код: открываешь **google.com/device** на телефоне или
   компьютере, входишь, вводишь код и выбираешь канал.

## Бесплатные обложки

В проекте появился раздел **«Обложки · бесплатно»**: автообложки выключены по умолчанию.
Включи «Кадр + надпись» и выбери стиль канала — Лимон, Океан или Коралл.
Для автоматической публикации бот берёт кадр из обработанного ролика и короткую надпись
из названия. Это локальные FFmpeg + Pillow, без AI-запросов и расходов токенов.
Надпись не является анализом сюжета: используется начало названия без хештегов.

При ручном выборе ролика или вводе ссылки открывается **«Подготовить ролик»**:
название, обложка и время публикации, без поля описания.
«Создать 3 варианта» скачивает исходник (для предпросмотра — до 720p), сравнивает
резкость и освещённость кадров в трёх частях ролика и предлагает три картинки.
Надпись можно изменить, затем нажать «Обновить надпись». Также можно загрузить
готовый JPG/PNG/WebP до 8 МБ и 24 мегапикселей. Своя картинка вписывается в 9:16 без обрезки.
Финальный JPG — 1080×1920, меньше 2 МБ. Для публикации сохраняется отдельная копия,
поэтому дальнейшее редактирование черновика её не меняет.

После загрузки видео бот отдельно пробует установить обложку через YouTube API.
Доступность пользовательских обложек Shorts зависит от YouTube и канала;
успешный ответ API не гарантирует показ картинки на всех поверхностях Shorts.
Если YouTube отклоняет обложку, видео не загружается повторно — приходит предупреждение
и JPG для ручной установки. JPG также отправляется при успешной установке.
Отправка в Telegram и обложка не отменяют успешную загрузку видео на YouTube.

Черновики находятся в `data/covers` и удаляются спустя сутки при создании новых.
Выбранные обложки в `data/covers/selected` сохраняются для запланированных публикаций
и ручного восстановления. На Windows используется Arial Bold; на Linux — DejaVu Sans Bold
или Liberation Sans Bold. Свой TTF можно указать переменной `COVER_FONT`.
После обновления установи зависимости (`.venv\Scripts\python -m pip install -r requirements.txt`)
и перезапусти бот.

## TikTok как источник

В «Откуда брать» можно вставить ссылку на TikTok-аккаунт (`https://www.tiktok.com/@ник`).

## ✂️ Умная обрезка видео

Укорачивает ролик до нужной длины так, чтобы резы были незаметны: режет только в паузах речи
(лучше всего — там, где пауза совпадает со сменой кадра), никогда посреди слова или фразы,
сохраняет хук (первые 3–5 с) и развязку, выкидывает «воду» и повторы целыми кусками.
На стыках — аудио-кроссфейд 50 мс и выравнивание громкости (loudnorm), затем автопроверка:
длина в допуске ±5%, нет щелчков, провалов громкости и чёрных кадров.

**В боте:** панель → **✂️ Умная обрезка** → выбери видео (загрузка идёт кусками прямо на твой
компьютер, поэтому лимит Telegram 20 МБ не мешает; максимум — `CUT_MAX_MB` / `CUT_MAX_MINUTES` в `.env`)
→ задай длину: вручную, «как на канале» (ссылка) или списком «длительность просмотры» → **Обрезать**.
Прогресс виден в панели и в чате; результат до 50 МБ бот пришлёт в чат, больше — одноразовой ссылкой
(срок `CUT_LINK_TTL_H`). Видео до 20 МБ можно просто отправить боту в чат.
Исходник удаляется сразу после обработки, результат — после выдачи или по сроку ссылки.

**AI-режим (необязательно, платно).** Если в `.env` задан `ANTHROPIC_API_KEY`, в обрезке появляется
галочка «🤖 AI-анализ Claude». Бот сначала бесплатно распознаёт речь и **показывает цену**
(«≈ $0.15 (≈ 13 ₽). Продолжить?» — [Да] [Нет, бесплатный режим]); без «Да» платных запросов нет.
После обработки — фактическая стоимость в отчёте и в логе расходов. Цены — в `pricing.yaml`.
По умолчанию AI доступен только владельцу бота (`CUT_AI_FOR_ALL=1` — всем).

**💳 Баланс Claude API** (панель, видишь только ты): внеси пополнения («Пополнил на $…»),
бот покажет «Остаток ≈ $X (пополнено − потрачено)». Потраченное бот считает по своим запросам;
с `ANTHROPIC_ADMIN_KEY` — раз в час берёт точные расходы организации из Anthropic Console.
При остатке ниже `CLAUDE_LOW_BALANCE_USD` — предупреждение; если оценка дороже остатка — AI не запускается.
Подписка Claude Pro к API не относится: баланс API пополняется отдельно на console.anthropic.com → Billing.

Из командной строки:

```
.venv\Scripts\python -m reuploader cut input.mp4 output.mp4 --target 58
.venv\Scripts\python -m reuploader cut input.mp4 output.mp4 --channel https://www.youtube.com/@канал
```

`--channel` — длина как у лучших роликов канала (медиана верхних 30% по просмотрам).
Речь распознаётся локально (faster-whisper, модель `small` скачается при первом запуске, ~500 МБ).
Тесты: `pip install -r requirements-dev.txt` и `python -m pytest tests`.

## Для продвинутых: командная строка без Telegram

Старый режим через `config.yaml` тоже работает (см. `config.example.yaml`):

```bash
python -m reuploader top https://www.youtube.com/@HappyFlick-b4e/shorts   # топ по просмотрам
python -m reuploader top <канал> --sort per_day --days 14 --token tokens/happyflick.json  # в день, за 2 недели
python -m reuploader auth --token tokens/happyflick.json                   # привязать канал
python -m reuploader run --dry-run                                         # скачать+обработать без заливки
python -m reuploader run                                                   # залить
python -m reuploader process input.mp4 output.mp4                          # только эффекты
```

## Структура

```
reuploader/
  source.py      список шортсов канала и скачивание (yt-dlp)
  effects.py     уникализация (ffmpeg)
  uploader.py    загрузка через YouTube Data API
  pipeline.py    общая логика выбора/обработки
  cli.py         командная строка
  bot/
    __main__.py  запуск бота, команды, уведомления, туннель
    scheduler.py расписание и выполнение публикаций
    planner.py   случайное время внутри окна
    worker.py    одна публикация
    web.py       API мини-апки и вход в Google
    db.py        SQLite (data/bot.db)
    webapp/      мини-апка
```
